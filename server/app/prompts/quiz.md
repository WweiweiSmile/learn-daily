<原文>

- 至少一道是**简答题**（kind = "short"），且不能靠背原文答出来——要让他用自己的话

  一眼就能排除的凑数项。
- 每道题都要给 rubric：答对必须包含的要点。批改时会拿它当尺子。
- 题目必须能在原文或讲解里找到依据，不要考没讲过的东西。
- 题干说清楚在问什么，不要出现「下列说法正确的是」这种含糊问法。

只返回 JSON，不要任何解释文字：

    }},
    {{
      "kind": "single",

    }}
